# Ecos do Encantado

## Um RPG Narrativo Baseado no Folclore Brasileiro

**Ecos do Encantado** é um jogo de RPG narrativo desenvolvido em **Godot 4.x**, ambientado em uma versão fantástica do Brasil inspirada no folclore brasileiro.

### 🎮 Gameplay

- **Exploração**: Percorra diferentes regiões carregadas de mistério
- **Narrativa**: Encontre personagens e entidades encantadas com histórias únicas
- **Decisões**: Suas escolhas moldam o destino da aventura
- **Combate**: Participe de batalhas por turnos estratégicas
- **Progressão**: Aumente seus atributos e desbloqueie novas habilidades

### 🏗️ Estrutura do Projeto

```
res://
├── assets/           # Sprites, sons, backgrounds
├── data/             # Dados do jogo (JSON, Resources)
├── scenes/           # Cenas do jogo
├── scripts/          # Lógica do jogo
├── resources/        # Recursos do Godot
├── autoload/         # AutoLoads globais
└── tests/            # Testes unitários
```

### 🚀 Como Executar

1. Abra o editor Godot 4.x
2. Carregue este projeto
3. Pressione `F5` para executar
